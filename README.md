# Silent Director (静默导演)

一个持续读取玩家状态的服务端导演系统，驱动一个类玩家 AI 实体。单人时它是“有脾气的对手”，多人时它是搅动社交化学反应的第三方。

## AI 使用披露
本模组代码实现大量使用了 AI 编程辅助工具。导演决策规则、角色行为意图、数值平衡与整体体验设计由人类完成。模组不依赖生成式 AI 在运行时生成内容；所有 AI 行为均由预定义规则和状态驱动，不调用外部 LLM。

## Alpha 已知限制
当前仅支持单人和 2–4 人；角色只有 NEUTRAL、HUNTER、OBSERVER、PROVIDER；暂无自定义模型、动画和音效；不保证与复杂内容模组兼容。
